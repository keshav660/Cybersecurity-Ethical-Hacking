2. Port & Service Scanning
2.1 Nmap Scanning Techniques
Basic Scan Types
TCP SYN Scan (Stealth Scan)

bash
nmap -sS 192.168.56.101
Advantages: Fast, stealthy, doesn't complete TCP handshake

Requirements: Root privileges

Detection: May trigger IDS/IPS

TCP Connect Scan

bash
nmap -sT 192.168.56.101
Advantages: No root privileges needed

Disadvantages: Completes full TCP handshake, more detectable

UDP Scan

bash
nmap -sU 192.168.56.101
Important UDP ports: 53(DNS), 67(DHCP), 123(NTP), 161(SNMP)

Note: UDP scanning is slow due to lack of responses

5. Firewall Configuration
5.1 iptables Fundamentals
Basic Syntax
bash
iptables -A CHAIN -p PROTOCOL --dport PORT -j ACTION
Common Chains
INPUT: Incoming traffic to firewall

OUTPUT: Outgoing traffic from firewall

FORWARD: Traffic through firewall

Common Actions
ACCEPT: Allow traffic

DROP: Block traffic (no response)

REJECT: Block traffic (send rejection)

LOG: Log traffic for monitoring

5.2 Practical iptables Rules
Basic Rule Set
bash
# Set default policies
iptables -P INPUT DROP
iptables -P FORWARD DROP
iptables -P OUTPUT ACCEPT

# Allow loopback interface
iptables -A INPUT -i lo -j ACCEPT
iptables -A OUTPUT -o lo -j ACCEPT

# Allow established connections
iptables -A INPUT -m state --state ESTABLISHED,RELATED -j ACCEPT

# Allow SSH (port 22)
iptables -A INPUT -p tcp --dport 22 -j ACCEPT

# Allow HTTP (port 80)
iptables -A INPUT -p tcp --dport 80 -j ACCEPT

# Allow HTTPS (port 443)
iptables -A INPUT -p tcp --dport 443 -j ACCEPT

# Allow DNS (port 53)
iptables -A INPUT -p udp --dport 53 -j ACCEPT
Port Scanning Protection
bash
# Limit connection attempts
iptables -A INPUT -p tcp --dport 22 -m limit --limit 3/min --limit-burst 3 -j ACCEPT

# Block port scanners
iptables -A INPUT -p tcp --tcp-flags ALL FIN,URG,PSH -j DROP
iptables -A INPUT -p tcp --tcp-flags ALL ALL -j DROP
iptables -A INPUT -p tcp --tcp-flags ALL NONE -j DROP

# Protect against SYN floods
iptables -A INPUT -p tcp --syn -m limit --limit 1/s --limit-burst 3 -j ACCEPT
Advanced Rules
bash
# Block specific IP address
iptables -A INPUT -s 192.168.56.200 -j DROP

# Block port range
iptables -A INPUT -p tcp --dport 1:1000 -j DROP

# Allow specific network
iptables -A INPUT -s 192.168.56.0/24 -j ACCEPT

# Log dropped packets
iptables -A INPUT -j LOG --log-prefix "IPTABLES-DROPPED: "
